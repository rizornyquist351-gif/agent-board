## 第 1 阶段：许愿最小闭环（单 agent）✅（D15）

**完成标准**：在网页上用一句话许愿 → 看到自动拆出的任务并点"开始" → 一个 agent 在独立分支里按顺序完成 → 页面实时显示它在做什么 → 用户点"通过"后合并到主分支（或点"打回"丢弃）。

- [x] 项目设置：启动时指定项目目录（`npm start -- 路径`），状态保存在 `项目/.agent-board/state.json`（git 自动忽略）
- [x] 许愿输入框 + 规划 agent：一句话 → 结构化任务清单（每个任务含目标、产出、边界、验收标准；D4）
- [x] 确认页：用户看拆出的任务，可删改，点"开始"
- [x] 执行器：为这次许愿建独立分支 / worktree（放在项目之外，D14），按顺序派任务，每个任务一个提交
- [x] 实时显示：用大白话显示 agent 当前在干什么，附过程记录
- [x] 失败处理：失败时停下并醒目提示，可重试 / 跳过 / 打回；也可随时手动停止
- [x] 审核：显示 agent 的总结、改动文件、完整 diff；"通过"合并（有未提交改动时拒绝）/ "打回"丢弃
- [x] 费用上限：规划 $0.5、每个任务 $2（可配置），界面显示花费

## 第 2 阶段：多 agent 并行（D16）

**完成标准**：一个愿望拆出的任务按依赖并行执行；多个愿望可同时进行；页面上一眼看到每个 agent 在做什么；验收时能按任务看报告和改动。

- [x] 规划：每个任务带角色（调研 / 开发）和依赖
- [x] 调度：依赖完成才开始；跨愿望全局最多 N 个 agent 同时干活
- [x] 调研员：只读 + 可上网，产出报告，报告传给后续任务
- [x] 开发者：各自独立 worktree，完成后自动合并进愿望分支；冲突时基于最新代码自动重做一次
- [x] Agent 面板：谁在做什么（跨所有愿望）
- [x] 确认页显示角色和依赖，可切换角色；验收页按任务看报告 / 改动
- [x] （开发中补充）验收合并时和项目最新代码冲突：自动追加"解决冲突"任务，解决后再验收

## 第 3 阶段：零配置与易用

**完成标准**：在项目目录里一条命令启动并自动打开浏览器；缺什么都在页面上用大白话说明；需要处理的事有提醒。

- [ ] 一条命令启动：`npx github:rizornyquist351-gif/agent-board`，自动打开浏览器
- [ ] 启动自检：git、Claude Code 是否可用，不可用时页面上说明怎么办
- [ ] 网页上切换项目
- [ ] `auto` 权限模式不可用时自动降级
- [ ] 提醒：标签页标题显示待处理数量，可选桌面通知
- [ ] 打磨：新手引导、空状态；更新 README 和在线预览
