## 第 1 阶段：发布与认领（预计 3–5 天）

**完成标准**：在网页上发布一条任务，agent 能自动领走并完成。

- [ ] 结构化发布表单，四项必填：目标、产出格式、可用工具/资料来源、任务边界；另加验收标准
- [ ] 原子认领：同一任务只能被一个 agent 领走
- [ ] 心跳 + 超时回收：agent 长时间无动静，任务退回待认领
- [ ] 任务状态：待认领 → 已认领 → 进行中 → 待审核 → 完成，另有 阻塞/失败

## 第 2 阶段：角色分工与审核（预计 1 周）

**完成标准**：调研报告和开发 PR 都挂在卡片上，人批准后才算完成。

- [ ] 角色：调研 agent（产出报告）、开发 agent（产出 PR）
- [ ] 按角色匹配认领
- [ ] 「待审核」列 + 人工批准 / 打回
- [ ] WIP 上限：限制同时进行的任务数（开发任务尤其要严格）
- [ ] 改动同一批文件的开发任务按顺序排队
